# ذی‌نفعان

## ذی‌نفع اصلی

**رئیس کل بیمه مرکزی**

- نیاز به دید کلان و مقایسه‌ای از کل بازار بیمه
- تمرکز روی سلامت فنی بازار، تمرکز قدرت، ریسک‌های سیستمی و عملکرد شرکت‌ها
- عدم نیاز به جزئیات عملیاتی روزانه یک شرکت خاص

## ذی‌نفعان ثانویه

| نقش | نیاز اطلاعاتی |
|-----|----------------|
| معاونت‌های تخصصی بیمه مرکزی | عمق بیشتر در رشته یا حوزه خود |
| شورای عالی بیمه | رتبه‌بندی و مقایسه شرکت‌ها |
| تیم تحلیل داده / BI | مدل داده و قوانین طراحی برای پیاده‌سازی |

## اصل حاکم

تمام تصمیمات طراحی باید از فیلتر «آیا این از دید رئیس کل معنادار و قابل اقدام است؟» عبور کند.
اگر یک پنل فقط برای تحلیل‌گر داده مفید باشد و برای رئیس کل گنگ باشد، پذیرفته نیست.
