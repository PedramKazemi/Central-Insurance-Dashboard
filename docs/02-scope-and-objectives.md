# دامنه و اهداف

## هدف اصلی

طراحی مجموعه‌ای از داشبوردهای مدیریتی سطح‌بالا برای **رئیس کل بیمه مرکزی** تا بتواند با یک نگاه وضعیت کلان صنعت بیمه را رصد کند.

## داخل دامنه (In Scope)

- حداقل ۵ داشبورد متمایز
- تمرکز روی شاخص‌های کلان بازار (حق‌بیمه، خسارت، نسبت خسارت، سهم بازار، شبکه فروش، جغرافیا)
- شش رشته اصلی: ثالث، بدنه، آتش‌سوزی، عمر، باربری، مشترکات
- مدل داده مبتنی بر Dimension و Fact ارائه‌شده
- سازگاری با Grafana 13
- حالت نمایشی (دمو) تمیز بدون توضیحات فنی پیاده‌سازی
- نقشه ایران برای نمایش جغرافیایی
- توضیحات شفاف شاخص‌ها (به‌ویژه نسبت خسارت و HHI)

## خارج از دامنه (Out of Scope)

- پیاده‌سازی واقعی کوئری‌های SQL در محیط production
- اتصال زنده به دیتابیس
- داشبوردهای عملیاتی سطح شعبه یا نمایندگی (جزئیات روزانه)
- طراحی برای مدیران شرکت‌های بیمه (تمرکز فقط روی دید رگولاتور/رئیس کل)
- پیش‌بینی و مدل‌های پیش‌بینی‌کننده پیچیده

## اهداف کیفی

| هدف | معیار موفقیت |
|-----|--------------|
| شفافیت | هیچ شاخصی بدون واحد و تعریف نباشد |
| یک‌نگاهی بودن | KPIهای اصلی در بالای صفحه و قابل درک در کمتر از ۳۰ ثانیه |
| زیبایی | تم تیره حرفه‌ای، فاصله‌گذاری مناسب، رنگ‌بندی معنادار |
| قابلیت پیاده‌سازی | استفاده از پنل‌های استاندارد Grafana 13 |
| انطباق با بازخورد | تمام نکات مطرح‌شده توسط کاربر اعمال شده باشد |
